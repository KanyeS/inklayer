    Marks stay put

    The page changes. The comment doesn't get lost.

    Each mark is attached to an element through several independent anchors, and shapes are stored relative to that element. When the layout shifts, the screen is a different size, or a single-page app navigates, marks follow.

    • CSS selectors (shadow DOM aware), XPath, the text itself, and its original position
    • If the element is gone, the mark stays where it was and is flagged as moved
    • Follows single-page-app navigation and DOM changes

    Live cursors

    See who's on the page with you.

    Turn on live cursors from the toolbar popup and review together, like a design tool, but on the real site. Everyone's pointer shows in their colour with a name tag, their text selection is tinted, and a row of faces shows who is here.

    • Positions travel as anchors, so a cursor over a paragraph stays over that paragraph on a different screen size
    • Idle cursors fade after ten seconds
    • Works on pages and in docs. Administrators can switch it off

    The right page, and only that

    You choose which address a comment belongs to.

    When a page's address has a query string or #hash, the person commenting chooses: every version of the page, or only that exact address. Only the parts they pick are stored, so tracking parameters and tokens stay out.

    • The extension keeps a list of domains that have comments, nothing more
    • It sends a full address only on those sites, or when you choose Comment on this page
    • Each comment shows the address it belongs to

        Sign-in and security

        Your server, your sign-in, your rules.

        Inklayer stores no passwords. People sign in with Google or your own single sign-on, and roles decide what they can do in each organisation and project.

        Single sign-on only

        Google, or any OpenID Connect provider. Verified domains let a whole company join automatically.

        GoogleJumpCloudOktaEntra IDAny OIDC

        Sealed off from the page

        The overlay and panel live in closed shadow roots, so a site's CSS and scripts can't restyle or read them. The page never sees a token.

        Behind your VPN

        Optionally limit the whole server to your networks. Lockout protection stops an admin from shutting themselves out.

        Short-lived tokens

        The extension uses short bearer tokens with rotating refresh tokens; the web app an HttpOnly cookie with CSRF checks.

        Instant revocation

        Disabling a user or "sign out everywhere" ends every cookie and token immediately.

        Permissive licences only

        Apache-2.0, and every dependency is MIT, Apache, BSD or ISC. CI enforces it.

        Administration

        Everything an administrator needs, in one place.

        The web app manages organisations, members, projects and their commented pages. Instance administrators also get:

        Users

        Every account on the server. Disable someone or sign them out everywhere.

        Features

        Turn Docs, Live cursors, AI assistants (MCP), Bug context, Issue trackers and Sharing on or off for everyone, instantly. Nothing is deleted.

        Network access

        An allow list of addresses and CIDR ranges, IPv4 or IPv6, with your own address shown and protected.

        Shared links

        Every working read-only link on the server, with view counts, and a switch to turn each off.

        Activity log

        Comments and sign-ins, plus refused sign-ins and server errors (never query strings or bodies), kept 30 days.

        Organisations and roles

        Invitations, allowed email domains with a default role, and per-project role changes.

        Integrations

        Email, Slack and signed webhooks per organisation, with the last delivery error shown.

        Issue trackers

        GitHub, Jira Cloud and Linear per project. Credentials checked before saving, stored encrypted.

        Connected apps

        MCP clients each person has allowed, and a button to disconnect them.

        Self-host

        One container. One SQLite file. Yours.

        The server is ASP.NET Core with a SQLite database on a single volume. Put a TLS reverse proxy in front and you're done.
